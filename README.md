# EurekaWM

## about

EurekaWM is a Window manager (as the name suggests) focused on
comfort, usability and functionality.
It uses "infinite canvas" idea but expanded, there are workspaces, 
every workspace is a separate canvas, you can manage them
eurekaWM provides some functionality out of the box (such as app picker, 
workspace manager, etc), to ensure user comfort and feature integration, 
while providing smooth experience.

## main idea

the main idea is: every workspace is its own infinite canvas.

## planned

- native Wayland support
- native X11 support
- native custom protocol
- app picker
- infinite canvas workspaces
- integrated debug API
